# Ana State Model

## Goal

Make current project context visible without pretending that inference is certainty.

## Layers

### Fact
Directly supported and stable enough to treat as known for the stated period.

### Observation
What was said, done or measured in a source.

### Hypothesis
A falsifiable interpretation. Requires evidence for, evidence against and a falsification condition.

### State
A dated operational snapshot assembled from facts/observations/hypotheses. It expires.

### Decision
An explicit human or authorized project decision.

## State dimensions

- current_goal
- current_focus
- active_constraints
- active_commitments
- open_decisions
- active_experiments
- current_resources_in_use
- current_friction
- recent_progress
- learning_preferences_observed
- communication_preferences_observed
- confidence
- freshness

Do not infer sensitive traits. Prefer Ana's own wording where available.
