# Workshops

Each workshop gets one folder:

YYYY-MM-DD-topic/
- brief.md
- agenda.md
- participant-material.md
- facilitator-guide.md
- evidence-used.md
- outcomes.md
- assets/

## Rules

- Store reusable workshop assets in Git only when they contain no private participant data.
- Store raw notes/transcripts in restricted Drive.
- Promote final decisions and durable learning to Confluence.
- Promote actions to Jira.
- Every workshop must state its intended observable outcome.
