# Workshops

Store reusable workshop design artifacts here. Store Ana-specific confidential source material in the restricted evidence system and link it by stable reference.

## Package structure

Each workshop should contain:
- objective.md
- facilitator-guide.md
- participant-view.md
- methods.md
- assets/
- evidence-map.md
- follow-up.md
- retrospective.md

## Workshop lifecycle

IDEA -> DESIGNED -> READY -> DELIVERED -> FOLLOW-UP -> INTEGRATED / RETIRED

A workshop is READY only when:
- intended outcome is explicit;
- audience and context are known;
- inputs are available;
- methods have a reason for use;
- participant-facing material is understandable without the backend harness;
- follow-up evidence is defined.

## Reuse rule

Separate reusable method assets from Ana-specific evidence. Reusable components should be written so they can become DYAI Studio assets without carrying Ana's private information.
